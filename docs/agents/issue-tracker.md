# Issue tracker: Local Markdown

Issues and specs live under `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- Specification: `.scratch/<feature-slug>/spec.md`
- Tickets: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Number tickets from `01`; do not combine them into one file.
- Record state with a `Status:` line near the top.
- Append discussion under `## Comments`.

When publishing or fetching an issue, create or read the corresponding Markdown file directly.
